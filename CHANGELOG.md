# Changelog

All notable changes to boilerlift are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html). While the version is below 1.0, a minor version can contain breaking changes.

Each release adds its section below this line, newest first, as `## [X.Y.Z] - YYYY-MM-DD`. The release skill writes it (`.claude/skills/release/SKILL.md`): do not edit this file by hand in a feature pull request.
